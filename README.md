## 9. SISTEMA DE AGENDAMENTO — FUNCIONAL E PERSISTENTE

ESTA É UMA DAS PARTES MAIS IMPORTANTES DO PROJETO.

Criar um sistema de agendamento com calendário interativo e integração real com Supabase.

Fluxo para a cliente:

**ETAPA 1 — ESCOLHER O SERVIÇO**

Exibir os serviços disponíveis em cards selecionáveis.

**ETAPA 2 — ESCOLHER A DATA**

Mostrar um calendário mensal moderno e intuitivo.

- Destacar a data selecionada.
- Bloquear datas anteriores.
- Mostrar datas indisponíveis.
- Respeitar folgas e bloqueios da profissional.
- Consultar a disponibilidade real cadastrada no banco.
- Registrar a data selecionada no Supabase como evento de seleção, mesmo antes de finalizar o agendamento, sem registrar dados pessoais desnecessários.

**ETAPA 3 — ESCOLHER O HORÁRIO**

Mostrar horários disponíveis como botões elegantes.

Os horários deverão ser gerados conforme:

- Funcionamento cadastrado pela administradora.
- Duração do serviço.
- Intervalos entre atendimentos.
- Horários bloqueados.
- Agendamentos confirmados.
- Datas especiais e feriados configurados manualmente.

O horário de encerramento informado é 19h, mas o painel deverá permitir configurar o horário de abertura e a grade de cada dia.

Nunca apresentar horários inventados como se fossem disponíveis.

**ETAPA 4 — DADOS DA CLIENTE**

Solicitar:

- Nome completo.
- WhatsApp com DDD.
- Serviço escolhido.
- Data selecionada.
- Horário desejado.
- Observações opcionais.

Adicionar aceite da política de privacidade.

**ETAPA 5 — ENVIAR SOLICITAÇÃO**

Botão principal:

**SOLICITAR MEU AGENDAMENTO**

Ao clicar:

1. Validar os dados.
2. Verificar novamente a disponibilidade.
3. Salvar uma solicitação real no Supabase.
4. Registrar o status inicial "Pendente de confirmação".
5. Gerar um número de protocolo.
6. Preparar a mensagem para o WhatsApp da Maria.
7. Direcionar a cliente para o WhatsApp com a mensagem preenchida.
8. Exibir uma tela de sucesso explicando que a solicitação ainda precisa ser confirmada.

IMPORTANTE: só encaminhar ao WhatsApp depois de salvar a solicitação com sucesso.

Se ocorrer erro ao salvar, mostrar uma mensagem clara e permitir tentar novamente, sem criar duplicatas.

A cliente precisará pressionar "Enviar" no WhatsApp. Não apresentar o preenchimento da mensagem como envio automático.

### AVISO OBRIGATÓRIO

Mostrar de forma destacada, antes e depois do envio:

**"Atenção: o horário solicitado está sujeito à disponibilidade e à confirmação da profissional. Seu agendamento só estará confirmado após o retorno da Maria pelo WhatsApp."**

Não usar "Agendamento confirmado" antes da confirmação administrativa.

No calendário, horários ocupados por atendimentos confirmados devem estar indisponíveis. Solicitações pendentes não deverão ser tratadas automaticamente como atendimentos confirmados; oferecer à administradora uma política configurável para reservas temporárias, evitando conflitos.
